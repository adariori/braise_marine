1. Module : Navigation (Le "Cerveau" du Header)
C’est la première chose que l'utilisateur manipule.

Étape 1 : Créer un "écouteur" sur le bouton hamburger pour ouvrir/fermer le menu mobile.

Étape 2 : Ajouter un effet au défilement (scroll) : si l'utilisateur descend de plus de 50px, le header change de couleur ou devient plus petit.

Étape 3 : Gérer la fermeture automatique du menu quand on clique sur un lien (pour ne pas rester bloqué sur le menu).

2. Module : Menu Dynamique (Affichage & Filtres)
Ici, on arrête d'écrire le HTML à la main pour les plats.

Étape 1 : Créer ta "base de données" (un tableau d'objets JS) contenant tous tes plats, leurs prix, catégories et accompagnements.

Étape 2 : Créer une fonction de rendu : elle parcourt tes données et génère le code HTML de chaque carte de plat automatiquement.

Étape 3 : Créer le système de filtrage : quand on clique sur "Poissons", le JS cache tout sauf les poissons.

3. Module : Configurateur de Commande (La Logique Métier)
C'est la partie la plus "intelligente" qui gère les options.

Étape 1 : Créer une fenêtre (modal) qui s'ouvre quand on clique sur un plat pour choisir l'accompagnement (Riz, Alloco, etc.).

Étape 2 : Calculer le prix en temps réel : Prix Plat + Prix Option.

Étape 3 : Gérer le choix "Sur place" vs "Livraison" pour ajouter ou non les frais de port.

4. Module : Formulaires (Réservation & Livraison)
Pour s'assurer de recevoir des données propres.

Étape 1 : Empêcher l'envoi du formulaire si des champs sont vides (Validation).

Étape 2 : Vérifier la logique des dates (interdire de réserver dans le passé).

Étape 3 : Afficher un message de succès animé à la place du formulaire après validation.

Module 2 (Suite) : L'Intelligence du Menu
Étape 3 : Le Filtrage Dynamique

Le but : Créer une "passoire" pour trier tes plats.

En JS : On va apprendre à utiliser .filter(). C'est une fonction qui crée une nouvelle liste à partir de la tienne en ne gardant que ce qui nous intéresse (ex: seulement les poissons).

L'action : Quand on clique sur un bouton "Poissons", on vide la grille HTML et on relance la fonction d'affichage uniquement avec la liste filtrée.

Module 3 : Le Configurateur (La Logique Métier)
Étape 1 : La Fenêtre de Personnalisation (Modal)

Le but : Quand on clique sur un plat, une petite fenêtre s'ouvre pour choisir l'accompagnement (Riz, Alloco, Patate douce).

En JS : On va apprendre à créer un élément "flottant" qui récupère les infos du plat cliqué.

Étape 2 : Le Calcul du Prix en temps réel

Le but : Si le client ajoute un supplément (ex: double sauce ou boisson), le prix doit changer sous ses yeux avant qu'il ne valide.

En JS : On va créer une petite variable total qui s'additionne à chaque fois qu'une case est cochée.

Module 4 : Les Formulaires (Validation & Propreté)
Étape 1 : Sécurité de la Réservation

Le but : Empêcher le client d'envoyer un formulaire vide ou de réserver pour une date déjà passée (ex: réserver pour hier).

En JS : On va utiliser les objets Date pour comparer l'heure actuelle avec l'heure choisie par le client.

Étape 2 : L'Effet de Succès (L'animation de fin)

Le but : Au lieu de recharger la page (ce qui est moche), on va faire disparaître le formulaire et faire apparaître un message animé : "C'est réservé ! 🍗".

En JS : On va manipuler les classes CSS pour créer cette transition fluide.
