Client → Reservation (un client réserve)
Client → Commande (un client passe une commande)
Categorie → Plat (un plat appartient à une catégorie)
Plat → LigneCommande (un plat apparaît dans une ligne)
Accompagnement → LigneCommande (l'accompagnement choisi)
Commande → LigneCommande (une commande a plusieurs lignes)
Livreur → Commande (un livreur livre une commande)



🔴 Priorité haute
1. API Commandes
Quand le client clique "Passer la commande", rien n'est encore enregistré en base. Il faut créer backend/api/commandes.php qui reçoit les données et les enregistre dans les tables Client, Commande et LigneCommande.
2. API Réservations
Le formulaire de réservation affiche juste "Réservation réussie !" sans rien enregistrer. Il faut créer backend/api/reservations.php.

🟡 Priorité moyenne
3. Paiement Stripe
Intégrer Stripe pour que le client puisse payer en ligne avant que la commande soit validée.
4. Page d'administration
Une interface simple pour que le patron puisse :

Voir les commandes reçues
Gérer les plats (ajouter, modifier, supprimer)
Voir les réservations


🟢 Priorité basse
5. Suivi de commande
Une page où le client peut voir le statut de sa commande en temps réel.
6. Gestion des livreurs
Assigner un livreur à une commande depuis l'interface admin.
